French-to-English Translation with Seq2Seq LSTM

Neural machine translation using Sequence-to-Sequence LSTM encoder-decoder architecture for French-English language pairs.

2024 Machine Translation Seq2Seq
Python TensorFlow / Keras LSTM Seq2Seq Encoder-Decoder Tokenization NLP BLEU Score

Project Overview

This project implements a Sequence-to-Sequence (Seq2Seq) LSTM model for neural machine translation (NMT) from French to English. The encoder-decoder architecture processes a variable-length French sentence and generates the corresponding English translation, word by word — a foundational approach in modern NLP before the Transformer era.

Architecture: Encoder-Decoder

The Seq2Seq model consists of two LSTM networks:

  • Encoder LSTM: Reads the French input sequence token by token and compresses the entire meaning into a fixed-size context vector (the final hidden and cell states).
  • Decoder LSTM: Takes the context vector as its initial state and generates the English translation one token at a time, conditioned on the previous predicted token (teacher forcing during training).

Training Pipeline

  1. Data Preparation: Loaded French-English sentence pairs. Applied tokenization, vocabulary building, and integer encoding. Padded sequences to uniform length.
  2. Teacher Forcing: During training, the decoder receives the ground-truth previous token as input at each step, accelerating convergence.
  3. Inference: At test time, the model generates translations autoregressively — each predicted token is fed back as the next decoder input until the <EOS> token is produced.
  4. Evaluation: BLEU score to measure translation quality against reference translations.

Seq2Seq insight: The encoder's final hidden state acts as a "thought vector" summarizing the source sentence. The quality of this representation is the bottleneck — which motivated the later development of attention mechanisms.

Key Results

  • Built a functional French-English NMT system from scratch using LSTM encoder-decoder.
  • Demonstrated teacher forcing training and autoregressive inference pipelines.
  • Evaluated translation quality with BLEU score on held-out test sentences.
  • Solid foundation for extending to attention-based models and Transformers.
