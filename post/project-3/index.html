Celebrity Face Generation with VAE

Generating realistic human faces by learning a structured latent space of the CelebA dataset using a Variational Autoencoder.

2024 Generative Model Computer Vision
Python TensorFlow / Keras VAE CelebA Dataset KL Divergence SSIM Latent Space Convolutional Neural Networks

Project Overview

This project implements a Variational Autoencoder (VAE) to generate new, realistic celebrity face images. Trained on the large-scale CelebA Faces dataset (200,000+ celebrity images), the model learns a continuous, structured latent space where new faces can be sampled — demonstrating the power of probabilistic deep learning for image synthesis.

Architecture

The VAE consists of two main components:

  • Encoder: Convolutional layers that compress the input image (64×64×3) into a latent representation — the mean (μ) and log-variance (log σ²) of a Gaussian distribution.
  • Decoder: Transposed convolutional layers that reconstruct the image from a sample drawn from the latent distribution using the reparameterization trick.

Loss Function

Total Loss = Reconstruction Loss + β × KL Divergence

The reconstruction loss measures how well the decoder reproduces the original image. The KL divergence regularizes the latent space to follow a standard Gaussian distribution, enabling smooth interpolation and meaningful sampling.

Evaluation

Model quality was assessed using the Structural Similarity Index (SSIM), which measures perceptual similarity between generated and real images — a more meaningful metric than pixel-level MSE.

Key Results

  • Successfully trained a convolutional VAE on CelebA to generate novel, photorealistic-style face images.
  • Demonstrated smooth latent space interpolation — walking between two latent vectors produces semantically meaningful face morphs.
  • Evaluated generation quality with SSIM, providing a quantitative benchmark for future improvements (β-VAE, VQ-VAE).
